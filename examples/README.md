# Examples

- **`engine/`** - multi-agent patterns on the raw engine (`Node`, `System`, executor).
- **`core-sdk/`** - the typed SDK over engine.
- **`llm/`** - the same SDK with `fedotmas-llm` (needs a `.env` API key).
- **`meta/`** - shipped pipelines from `fedotmas-meta` (selector -> menu -> run), stubs by default.
